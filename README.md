# HACK ERA 1.0 — Hackathon Project

## About the Project
[Project Name: FarmVerse – 3D Interactive Virtual Farm

Project Work: FarmVerse is an AI-powered smart farming platform that allows farmers to explore farming decisions in a virtual 3D environment. Users can select crops, adjust irrigation, explore fertilizer strategies, and compare different farming scenarios. The system estimates farming costs, water usage, potential crop yields, and profits. An AI Farming Advisor provides explanations in Marathi, Hindi, and En

Objective: To help farmers understand farming options, compare possible outcomes, and make more informed decisions before applying them to their real farms..]
